# Palette's UX Journal

## Critical UX/Accessibility Learnings

## 2025-05-22 - [Standard Accessibility Setup]
**Learning:** Modern e-commerce sites often forget foundational a11y like 'Skip to content' and aria-labels on icon buttons, which are critical for screen reader users and keyboard navigation.
**Action:** Always check for 'Skip to content' links and aria-labels on interactive icon-only elements as a first step in any project.
