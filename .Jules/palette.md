## 2025-05-15 - [Navigation & Keyboard Accessibility]
**Learning:** Single Page Applications (SPAs) often neglect keyboard navigation and screen reader context during route changes. Missing 'Skip to main content' links and 'aria-current' markers create friction for non-mouse users.
**Action:** Implement a standard 'Skip to main content' link and ensure 'aria-current="page"' is applied to active navigation links in all layouts.
