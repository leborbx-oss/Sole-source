## 2025-05-15 - [Accessibility Baseline]
**Learning:** The 'SOLE SOURCE' application currently lacks essential keyboard accessibility and screen reader support. Critical elements such as the skip-to-content link, ARIA labels for icon-only buttons, and active link states are missing.
**Action:** Implement a standard 'Skip to main content' link, add ARIA labels to all interactive icon-only components, and use 'aria-current="page"' for navigation.
