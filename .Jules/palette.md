# UX/Accessibility Journal - SOLE SOURCE NBA Game

## Critical Patterns
- **High-Precision Game Loop**: Aiming for 10,000 UPS for physics simulation.
- **Vite/React/Three.js**: Core tech stack for the game.
- **Accessibility**: ARIA labels for game controls and focus states.

## Design Constraints
- **Performance**: High detail models (high-poly) but must maintain smooth FPS.
- **Realism**: PBR materials, dynamic lighting, and realistic movement.
