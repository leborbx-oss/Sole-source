# Palette's UX Journal

## 2025-05-14 - Initial Accessibility Audit
**Learning:** The application lacks basic keyboard navigation supports like a "Skip to main content" link and ARIA labels on icon-only interactive elements, which is a common pattern in early-stage SPAs.
**Action:** Implement a standard "Skip to main content" pattern and ensure all icon-only buttons have descriptive ARIA labels with proper pluralization for counts.
