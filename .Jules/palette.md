## 2025-05-15 - Accessibility Audit Patterns
**Learning:** The application's minimalist design system heavily uses icon-only buttons (Search, Shopping Bag, Menu) and custom interaction patterns (Cart quantity buttons) that lacked semantic labels and keyboard navigation aids.
**Action:** Prioritize adding 'aria-label' to all icon-only interactive elements and implement 'Skip to main content' links to bridge the gap between minimalist aesthetics and functional accessibility.
