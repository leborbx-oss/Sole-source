# Palette UX/Accessibility Journal

## 2025-05-14 - Skip to Main Content & Navbar Accessibility
**Learning:** Implemented "Skip to main content" link for keyboard users and added proper ARIA attributes (`aria-label`, `aria-expanded`, `aria-current`) to improve navigation accessibility for screen readers.
**Action:** Always ensure a skip-to-content link is present in the main layout and interactive components have descriptive labels and state indicators.
