## 2025-05-22 - Global Accessibility Improvements
**Learning:** In Single Page Applications (SPAs), route changes do not automatically reset focus. Implementing a "Skip to main content" link and explicit ARIA markers (aria-current, aria-expanded) is critical for providing context to keyboard and screen reader users after navigation.
**Action:** Always include a 'Skip to main content' link and appropriate ARIA attributes for navigation and interactive elements to ensure a baseline of accessibility.
